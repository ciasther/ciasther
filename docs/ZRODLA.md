# Inspiracja i źródła

Research: 16 września 2026. Treść profilu opiera się na podanym koncie GitHub i kontekście pracy przekazanym przez właściciela. To propozycja publicznej prezentacji, nie automatycznie zweryfikowane CV ani deklaracja stażu.

**Inspiracja, nie kopia:** [Andrew6rant/Andrew6rant](https://github.com/Andrew6rant/Andrew6rant) wykorzystuje ASCII, terminalowy sposób prezentacji, warianty jasny/ciemny oraz statystyki. Układ, treść, kolorystyka, portret i generator tej paczki powstały osobno. Nie skopiowano jego `today.py` ani SVG. Nie przypisujemy temu repozytorium żadnej niezweryfikowanej licencji.

**Portret:** dane ASCII pochodzą z kadru dostarczonego zdjęcia. Paczka nie zawiera oryginalnej fotografii, drugiej osoby, danych EXIF, plików fontów ani osadzonych fontów. Raster nie jest wysyłany do usługi generującej karty; generator odczytuje lokalną tablicę znaków.
