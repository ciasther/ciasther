<summary>How the live numbers are calculated</summary>

- `Repos` — repositories owned by `ciasther`, public + private.
- `Code` — current non-empty source lines on default branches of owned, non-fork repositories. Dependencies, build output, lockfiles, generated/vendor directories and binaries are excluded.
- `Commits / Added / Deleted / Net` — commits reachable from each owned repository's default branch, authored by the GitHub user or by an e-mail not linked to any GitHub account. Bots and other GitHub users are skipped. Identical commit OIDs are counted once. Windows are rolling `7 / 30 / 365` days; `life` means all counted commits.
- Private repository names, paths, commit messages and source code are never written to this public repository. Only aggregate numbers are persisted.
